# Ana Diwedi — Product & AI Portfolio

Interview-focused portfolio website covering AI/GenAI, digital banking, telecom, product analytics and customer experience.

## Publish with GitHub Pages
Upload all files and folders in this package to the repository root. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

The portfolio uses plain HTML/CSS and requires no build step.
